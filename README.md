# Clinica360 - Sistema de Gestión Clínica Salud Integral 

**Clinica360** es un sistema web desarrollado en **.NET / ASP.NET** diseñado para la gestión integral de clínicas médicas. Facilita el control de citas, expedientes de pacientes, registro de historial clínico y configuración de notificaciones en un solo entorno centralizado.

## 🚀 Funcionalidades del Sistema

### 1. Acceso al Sistema y Seguridad
* **Inicio de Sesión:** Autenticación de usuarios (personal médico y administrativo).
* **Registro de Usuarios:** Creación de nuevas cuentas en la plataforma.
* **Recuperación de Contraseña:** Envío de código de verificación de 5 dígitos vía correo electrónico para el restablecimiento seguro de credenciales.

### 2. Dashboard Principal (Panel de Control)
* **Métricas Diarias:** Resumen de citas programadas, pacientes atendidos, pendientes y cancelaciones (*"No asistió"*).
* **Agenda Corta:** Vista rápida con detalles del paciente, hora, motivo de consulta y estado (*Atendido, Vencida, Programada*).

### 3. Gestión de Pacientes
* **Búsqueda:** Filtrado rápido de pacientes por nombre, cédula o teléfono.
* **Ficha del Paciente:** Registro detallado con datos básicos (cédula, edad, contacto), alergias e historial de consultas.

### 4. Gestión de Citas y Agenda
* **Programación:** Registro de citas asociando paciente, doctor disponible, fecha y hora exactas.
* **Control de Horarios:** Calendario interactivo (vista semanal/mensual) codificado por colores para prevenir empalmes de citas.

### 5. Historial Clínico
* **Expediente Digital:** Acceso al historial del paciente desde los módulos de Médicos o Pacientes.
* **Registro de Atención:** Formularios para motivo de consulta, diagnóstico y emisión de recetas médicas digitales (especificando medicamento, dosis e indicaciones).

### 6. Configuración y Ajustes
* **Perfil Médico:** Edición de datos personales, correo institucional y especialidad médica.
* **Plantillas de Recordatorios:** Configuración de mensajes automáticos para recordar citas a los pacientes.
